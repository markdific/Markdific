# Markdific

**A better way to open, read, edit, and export Markdown files.**

Markdific is a [Markdown viewer and editor](https://markdific.com) for Mac, Windows, and Linux. Open `.md` files as formatted documents, edit visually in WYSIWYG mode, or work with Markdown source and a live preview. Export finished documents to PDF, Word, or HTML.

## Download and install Markdific

### macOS 12 or later

1. [Download Markdific for Mac](https://licenses.markdific.com/download/mac).
2. Open the downloaded installer.
3. Move Markdific into the **Applications** folder if the installer asks you to do so.
4. Open Markdific from Applications.
5. Open an `.md` file from Markdific, drag the file into the app, or make Markdific the default app for Markdown files.

After installation, you can also select an `.md` file in Finder and press the **Space bar** to preview it with Markdific Quick Look.

### Windows 10 or 11

1. Open [Markdific in the Microsoft Store](https://apps.microsoft.com/detail/9p549vbtg01c?ocid=webpdpshare).
2. Select **Get** or **Install**.
3. Open Markdific from the Start menu after installation finishes.
4. Open or drag an `.md` file into Markdific.

Installing from the Microsoft Store also gives Windows the official Markdific app listing and update path.

### Linux

On [markdific.com](https://markdific.com/), select **Download → Download for Linux**. Choose your processor, then choose the package format for your distribution.

For an Intel or AMD 64-bit system:

* **Ubuntu, Debian, or Mint:** [Download the x64](https://licenses.markdific.com/download/linux-deb-x64) [`.deb`](https://licenses.markdific.com/download/linux-deb-x64) [package](https://licenses.markdific.com/download/linux-deb-x64), then install it with your software installer or `sudo apt install ./downloaded-file.deb`.
* **Fedora, RHEL, or openSUSE:** [Download the x64](https://licenses.markdific.com/download/linux-rpm-x64) [`.rpm`](https://licenses.markdific.com/download/linux-rpm-x64) [package](https://licenses.markdific.com/download/linux-rpm-x64), then install it with your package manager or `sudo dnf install ./downloaded-file.rpm`.
* **Other distributions:** [Download the x64 AppImage](https://licenses.markdific.com/download/linux-appimage-x64). Make it executable with `chmod +x downloaded-file.AppImage`, then run it. AppImage may require FUSE on your distribution.

For a 64-bit ARM system:

* **Ubuntu, Debian, or Mint:** [Download the arm64](https://licenses.markdific.com/download/linux-deb-arm64) [`.deb`](https://licenses.markdific.com/download/linux-deb-arm64) [package](https://licenses.markdific.com/download/linux-deb-arm64).
* **Fedora, RHEL, or openSUSE:** [Download the arm64](https://licenses.markdific.com/download/linux-rpm-arm64) [`.rpm`](https://licenses.markdific.com/download/linux-rpm-arm64) [package](https://licenses.markdific.com/download/linux-rpm-arm64).
* **Other ARM distributions:** [Download the arm64 AppImage](https://licenses.markdific.com/download/linux-appimage-arm64).

If you are unsure which Linux build to choose, run `uname -m` in a terminal. `x86_64` means the Intel/AMD x64 build. `aarch64` or `arm64` means the ARM build.

Package filenames change when Markdific is updated. In the commands above, replace `downloaded-file` with the actual name of the file you downloaded.

## Open Markdown files as readable documents

Markdown is easy to write, but a plain-text editor leaves the formatting symbols visible. Markdific turns the same file into a properly formatted document while keeping the original `.md` file available for other tools.

Open a Markdown file directly. You do not need to import it into a library, create a vault, or set up a project workspace.

Markdific displays:

* Headings and paragraphs
* Bold, italic, strikethrough, highlight, and links
* Bulleted, numbered, nested, and task lists
* Blockquotes and horizontal rules
* Tables with column alignment
* Inline code and fenced code blocks with syntax highlighting
* Inline and block LaTeX math
* Rendered Mermaid diagrams
* Web, local, and pasted images
* YAML front matter and other technical document content

Use the outline sidebar to jump between headings in a long document. Keep several files open in tabs, and return to documents through the recent-files list.

## Edit visually or work with Markdown source

Choose the editing view that suits the document and the way you work.

### WYSIWYG mode

Edit directly in the formatted document. Use the built-in toolbar to add headings, emphasis, lists, links, code, and other formatting without manually typing every Markdown marker.

### Source view

Work with the raw Markdown when you need complete control over the file. This is useful for README files, documentation, front matter, code fences, math, Mermaid, and syntax that must remain portable between applications.

### Split view with live preview

Place Markdown source beside the rendered document. The preview updates as you type, so you can inspect the syntax and formatted result at the same time.

Enable autosave when you want Markdific to save changes as you work. If autosave is off, Markdific warns you about unsaved changes before switching away from a file.

## Work with code, math, diagrams, and images

Markdific is designed for technical Markdown as well as ordinary notes.

### Syntax-highlighted code

Read fenced code blocks with language-aware syntax highlighting. The source remains inside the Markdown document, making the file suitable for technical instructions, examples, and project documentation.

### LaTeX math

View inline and block LaTeX expressions as rendered mathematics instead of raw delimiters and commands.

### Mermaid diagrams

Render Mermaid diagrams stored inside fenced code blocks. This lets a single Markdown file contain editable flowcharts, sequence diagrams, timelines, and other supported diagrams.

### Web, local, and pasted images

Display images from web URLs and local file paths in place. Images pasted into Markdific remain available after you save and reopen the file.

## Navigate and read long documents

Markdific includes tools for documents that are too large to manage comfortably in a basic text editor:

* Keep multiple Markdown files open in tabs.
* Use the outline sidebar to jump to any heading.
* Reopen files from the recent-files list.
* Adjust the document layout and content width.
* Choose a theme and font that are comfortable to read.
* Enter presentation mode for a focused, full-screen reading view.
* Adjust document width and line spacing while presenting or reading.

On Mac, select a Markdown file in Finder and press the **Space bar** to preview it with Quick Look without opening the full app.

## Export Markdown to PDF, Word, or HTML

Keep Markdown as the editable source, then create another format when you need to share, review, print, or publish the document.

* **PDF:** Create a fixed-layout copy for sharing or printing.
* **Word:** Export to an editable `.docx` document for people who work in Microsoft Word.
* **HTML:** Create an HTML version for publishing or use in another web workflow.

The original `.md` file remains a normal Markdown file that you can reopen in Markdific or another compatible application.
